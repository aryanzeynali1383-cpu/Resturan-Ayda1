
# سامانه هوشمند مدیریت رستوران (سرای پیتزا)

یک اپلیکیشن جامع برای مدیریت رستوران‌های فست‌فود که با استفاده از **React** و **Tailwind CSS** طراحی شده است.

## ویژگی‌های اصلی
- **میز کار هوشمند (Dashboard):** مشاهده آمار فروش، سفارشات جاری و تحلیل‌های آماری.
- **سیستم ثبت سفارش (POS):** رابط کاربری مدرن برای ثبت سفارشات بر اساس میز.
- **مانیتورینگ آشپزخانه (KDS):** مدیریت وضعیت پخت و آماده‌سازی غذاها به صورت زنده.
- **مدیریت انبار:** کنترل موجودی مواد اولیه و هشدار خودکار برای موارد رو به اتمام.
- **مدیریت منو:** افزودن، ویرایش و حذف آیتم‌های منو با دسته‌بندی و تصاویر.
- **مدیریت تیم:** مدیریت کارکنان، نقش‌ها و کنترل دستمزدها.

## تکنولوژی‌های مورد استفاده
- **Frontend:** React 19, Tailwind CSS
- **Routing:** React Router 7
- **Charts:** Recharts
- **Icons:** Emojis & SVG

## نحوه اجرا
این پروژه با ابزار Vite بیلد می‌شود. برای اجرا:

1. دستور `npm install` را اجرا کنید.
2. دستور `npm run dev` را برای حالت توسعه اجرا کنید.
3. برای دریافت خروجی نهایی جهت آپلود در هاست یا گیت‌هاب، دستور `npm run build` را اجرا کنید.
